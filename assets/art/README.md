# Original prototype artwork

All SVG artwork in this directory was created specifically for ARUPIGI.
The fixed irregular contours and muted pencil-and-watercolour palette intentionally avoid pixel art and frame-to-frame noise. No external image assets are used.

Terrain and markers use a 48 × 48 view box. Enemy portraits use 256 × 256. The player uses 48 × 48, with the feet near y = 41.

The NPC placeholder also uses 48 × 48 with the feet near y = 41; its Resource tint distinguishes residents.
